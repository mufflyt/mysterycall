# Convert a mysterycall_table1 to a flextable (internal)

Convert a mysterycall_table1 to a flextable (internal)

## Usage

``` r
as_flex_table.mysterycall_table1(x, ...)
```

## Arguments

- x:

  A `mysterycall_table1` object.

- ...:

  Passed to
  [`flextable::flextable()`](https://davidgohel.github.io/flextable/reference/flextable.html).

A `flextable` object.
