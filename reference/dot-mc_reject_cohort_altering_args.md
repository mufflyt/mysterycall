# Refuse Arguments That Would Change the Fitted Cohort

`subset` and `na.action` make the engine fit a different set of rows
than the complete-case cohort the fitter assembled and reports. The
cohort assertion would then fire with a message about undefined values,
which misdiagnoses the cause. Refuse them by name instead, and say what
to do.

## Usage

``` r
.mc_reject_cohort_altering_args(dots, fn_name)
```

## Arguments

- dots:

  A list of the `...` arguments the fitter received.

- fn_name:

  Character scalar naming the calling function.

## Value

`invisible(TRUE)`. Called for the error side effect.
