# Get nth Occurrence of a Weekday

Get nth Occurrence of a Weekday

## Usage

``` r
.mc_nth_weekday(year, month, weekday, n)
```

## Arguments

- year:

  Integer year.

- month:

  Integer month (1-12).

- weekday:

  Integer weekday (1=Sun, ..., 7=Sat).

- n:

  Integer occurrence (1st, 2nd, etc.).

## Value

Date object.
