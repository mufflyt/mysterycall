# Calculate Descriptive Statistics for Wait Times

Calculate Descriptive Statistics for Wait Times

## Usage

``` r
.wait_stats(x)
```

## Arguments

- x:

  Numeric vector of wait times.

## Value

A tibble with descriptive statistics (n, mean, sd, median, etc.).
