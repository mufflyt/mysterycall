# Build a Manuscript-Ready Insurance Wait-Time Sentence

Fits a Poisson GLM of wait time on insurance type (with Blue Cross/Blue
Shield as the reference), extracts the Incidence Rate Ratio (IRR),
confidence interval, and p-value for Medicaid, and assembles a
manuscript-ready sentence reporting the comparison.

## Usage

``` r
mysterycall_insurance_wait_sentence(
  data,
  outcome_col = "business_days_until_appointment",
  insurance_col = "insurance",
  medicaid_label = "Medicaid",
  bcbs_label = "Blue Cross/Blue Shield",
  digits_irr = 2L,
  digits_pct = 1L,
  digits_median = 0L,
  filter_positive = FALSE
)
```

## Arguments

- data:

  A data frame.

- outcome_col:

  Character scalar. Numeric wait-time column. Default
  `"business_days_until_appointment"`.

- insurance_col:

  Character scalar. Insurance column. Default `"insurance"`.

- medicaid_label:

  Character scalar. Label used for Medicaid in `insurance_col`. Default
  `"Medicaid"`.

- bcbs_label:

  Character scalar. Label used for Blue Cross/Blue Shield (reference
  group). Default `"Blue Cross/Blue Shield"`.

- digits_irr:

  Integer. Decimal places for IRR and CI. Default `2`.

- digits_pct:

  Decimal places for percentage difference. Default `1`.

- digits_median:

  Integer. Rounding digits for medians. Default `0`.

- filter_positive:

  Logical. If `TRUE`, pre-filter rows where `outcome_col > 0`. Default
  `FALSE`.

## Value

A named list:

- `sentence`:

  Character scalar – the manuscript paragraph.

- `irr`:

  Numeric IRR for Medicaid vs. BCBS.

- `ci_lower`:

  Numeric lower 95% CI bound.

- `ci_upper`:

  Numeric upper 95% CI bound.

- `p_value`:

  Numeric p-value.

- `pct_diff`:

  Numeric percentage difference `(irr - 1) * 100`.

- `medicaid_stats`:

  Named list: `median`, `q1`, `q3` for Medicaid.

- `bcbs_stats`:

  Named list: `median`, `q1`, `q3` for BCBS.

## Examples

``` r
set.seed(42)
df <- data.frame(
  insurance = rep(c("Medicaid", "Blue Cross/Blue Shield"), each = 20),
  business_days_until_appointment = c(rpois(20, 21), rpois(20, 10)),
  stringsAsFactors = FALSE
)
res <- mysterycall_insurance_wait_sentence(df)
cat(res$sentence)
#> Medicaid patients experienced a 94% longer wait compared to patients with Blue Cross/Blue Shield (Incidence Rate Ratio: 1.94; 95% CI: 1.65 to 2.27; p < 0.001) with median wait times of 22 business days (IQR: 19 to 26) and 11 business days (IQR: 10 to 12) respectively.
```
