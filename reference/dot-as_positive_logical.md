# Coerce Acceptance Column to Logical

Accepts logical, numeric, or character ("yes"/"y"/"true"/"1").

## Usage

``` r
.as_positive_logical(x)
```

## Arguments

- x:

  Vector to coerce.

## Value

Logical vector.
