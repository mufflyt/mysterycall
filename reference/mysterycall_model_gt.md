# Thin Wrapper: gt IRR Table from a Simple Poisson Result

Extracts `$irr_table` from a `mysterycall_simple_poisson` object and
passes it to
[`mysterycall_irr_table()`](https://mufflyt.github.io/mysterycall/reference/mysterycall_irr_table.md).

## Usage

``` r
mysterycall_model_gt(poisson_result, ...)
```

## Arguments

- poisson_result:

  An object of class `mysterycall_simple_poisson` (returned by
  [`mysterycall_simple_poisson()`](https://mufflyt.github.io/mysterycall/reference/mysterycall_simple_poisson.md)).

- ...:

  Additional arguments passed to
  [`mysterycall_irr_table()`](https://mufflyt.github.io/mysterycall/reference/mysterycall_irr_table.md).

## Value

A `gt_tbl` object.

## Examples

``` r
if (requireNamespace("gt", quietly = TRUE)) {
  set.seed(7)
  df <- data.frame(
    days      = rpois(60, 14),
    insurance = rep(c("BCBS", "Medicaid"), 30)
  )
  res <- mysterycall_simple_poisson(df, "days", "insurance",
                                    reference = "BCBS")
  mysterycall_model_gt(res)
}
```
