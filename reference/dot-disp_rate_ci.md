# Calculate Confidence Interval for Proportion

Calculate Confidence Interval for Proportion

## Usage

``` r
.disp_rate_ci(n_acc, n, method, conf_level, rate, alpha)
```

## Arguments

- n_acc:

  Number of successes.

- n:

  Total number of trials.

- method:

  CI method: "wilson", "exact", or "wald".

- conf_level:

  Confidence level (e.g., 0.95).

- rate:

  Observed proportion (n_acc / n).

- alpha:

  Significance level (1 - conf_level).

## Value

Numeric vector of length 2 (lower, upper).
