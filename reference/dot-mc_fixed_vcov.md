# Fixed-Effect Variance-Covariance Matrix From an Engine Fit

Returned as a base matrix: `lme4` supplies a `dpoMatrix`, which fails
[`is.matrix()`](https://rdrr.io/r/base/matrix.html) and cannot be
indexed the way callers expect.

## Usage

``` r
.mc_fixed_vcov(fit)
```

## Arguments

- fit:

  An engine fit.

## Value

Numeric matrix for the fixed effects (conditional model only).
