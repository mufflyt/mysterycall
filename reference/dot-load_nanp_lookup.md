# Load NANP Area Code Lookup Table

Loads and caches the mapping between US area codes and states.

## Usage

``` r
.load_nanp_lookup(nanp_path = NULL)
```

## Arguments

- nanp_path:

  Optional path to custom NANP CSV.

## Value

Data frame with `area_code` and `state` columns.
