# Sensitivity analysis across data subsets

Re-runs the same model specification across subsets of the data - e.g.
stratified by practice setting or geographic region, or excluding
zero-wait observations. Returns a combined table comparing IRRs across
subsets so the stability of the primary result can be assessed.

## Usage

``` r
mysterycall_sensitivity(
  data,
  outcome,
  predictors,
  random_intercept,
  subset_var = NULL,
  exclude_zeros = FALSE,
  family = c("auto", "poisson", "nb"),
  ref_group = NULL,
  baseline_mean = NULL,
  conf_level = 0.95,
  phi_threshold = 2,
  ...
)
```

## Arguments

- data:

  A data frame containing all model columns.

- outcome:

  Character scalar naming the count outcome column.

- predictors:

  Character vector of fixed-effect predictor column names.

- random_intercept:

  Character scalar naming the random-intercept grouping column.

- subset_var:

  Character scalar naming a column whose unique levels each define one
  subset. Pass `NULL` (default) to skip stratification.

- exclude_zeros:

  Logical. If `TRUE`, an additional subset excluding rows where
  `outcome == 0` is added. Default `FALSE`.

- family:

  One of `"auto"` (default), `"poisson"`, or `"nb"` (negative binomial).
  `"auto"` fits Poisson first and switches to NB if Pearson phi \>
  `phi_threshold`.

- ref_group:

  Character scalar. Label for the reference group used in manuscript
  sentences. Passed to
  [`mysterycall_irr_to_days()`](https://mufflyt.github.io/mysterycall/reference/mysterycall_irr_to_days.md)
  when `baseline_mean` is supplied. Default `NULL`.

- baseline_mean:

  Numeric scalar. If supplied, an absolute days difference column is
  added: `days_diff = baseline_mean * (IRR - 1)`.

- conf_level:

  Numeric. Confidence level for Wald CIs. Default `0.95`.

- phi_threshold:

  Numeric. Pearson phi above which `"auto"` switches to NB. Default
  `2.0`.

- ...:

  Additional arguments forwarded to the model-fitting function.

## Value

A list of class `mysterycall_sensitivity` with elements:

- `table`:

  Data frame with columns `subset_name`, `term`, `IRR`, `ci_lower`,
  `ci_upper`, `p_value`, `model_type`, and (if `baseline_mean` supplied)
  `days_diff`.

- `models`:

  Named list of fitted model objects, one per subset.

- `subsets_run`:

  Character vector of subset names that were successfully analysed.

- `family`:

  The `family` argument that was used.

## Examples

``` r
set.seed(42)
df <- data.frame(
  wait    = rpois(80, 18),
  ins     = rep(c("Medicaid", "BCBS"), 40),
  setting = rep(c("Academic", "Private", "Academic", "Private"), 20),
  phys    = rep(paste0("Dr", 1:20), each = 4),
  stringsAsFactors = FALSE
)
res <- mysterycall_sensitivity(
  df, "wait", "ins", "phys",
  subset_var = "setting",
  family     = "poisson"
)
#> Fitting Poisson GLMER: wait ~ ins + (1 | phys)
#> boundary (singular) fit: see help('isSingular')
#> Convergence issues detected:
#>   boundary (singular) fit: see help('isSingular')
#> Consider simplifying predictors or using nAGQ = 1.
#> Singular fit: random-intercept variance is ~0. The physician-level random effect explains little variation.
#> Model fitted: n=80, physicians=20, AIC=470.5, overdispersion=1.05
#> Fitting Poisson GLMER: wait ~ ins + (1 | phys)
#> Warning: Model fit failed for subset 'Academic': glmer() failed to fit: contrasts can be applied only to factors with 2 or more levels
#> Fitting Poisson GLMER: wait ~ ins + (1 | phys)
#> Warning: Model fit failed for subset 'Private': glmer() failed to fit: contrasts can be applied only to factors with 2 or more levels
print(res)
#> Sensitivity analysis (1 subsets, family = poisson)
#> 
#>  subset_name        term     IRR  ci_lower ci_upper   p_value model_type
#>  Full sample insMedicaid 1.03022 0.9303437 1.140818 0.5671653    poisson
#>     Academic        <NA>      NA        NA       NA        NA       <NA>
#>      Private        <NA>      NA        NA       NA        NA       <NA>
```
