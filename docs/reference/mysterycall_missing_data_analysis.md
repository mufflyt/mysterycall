# Test whether missing appointment dates are MAR or MNAR

Creates a binary missingness indicator for the appointment-date outcome
column and tests whether missingness is associated with key predictors
(insurance group, physician characteristics, caller identity). Rejection
of the null indicates that data are not Missing Completely At Random
(MCAR); the pattern is then interpreted as MAR or MNAR depending on
whether the predictors are themselves observed.

## Usage

``` r
mysterycall_missing_data_analysis(
  data,
  outcome_col,
  group_col = NULL,
  covariate_cols = NULL,
  alpha = 0.05
)
```

## Arguments

- data:

  A data frame.

- outcome_col:

  Character scalar. Name of the appointment-date (or numeric outcome)
  column to test for missingness. Rows where this column is `NA` are
  treated as missing.

- group_col:

  Character scalar or `NULL`. Primary grouping variable (e.g.
  `"insurance"`). Tested first and included in the summary table.

- covariate_cols:

  Character vector or `NULL`. Additional columns to test for association
  with missingness (e.g. physician characteristics, caller identity).

- alpha:

  Numeric. Significance threshold for interpretation. Default `0.05`.

## Value

A list of class `mysterycall_missing_data` with elements:

- `summary`:

  Data frame: one row per variable tested, columns `variable`,
  `n_observed`, `n_missing`, `pct_missing`, `test`, `statistic`, `df`,
  `p_value`, `significant`.

- `overall`:

  List: `n_total`, `n_missing`, `pct_missing`.

- `interpretation`:

  Character scalar. Plain-language MAR/MNAR interpretation based on
  significant tests.

- `group_table`:

  Data frame: missingness counts broken out by `group_col` levels, or
  `NULL` when `group_col` is `NULL`.

- `outcome_col`:

  Character. Name of the outcome column tested.

## Details

For categorical predictors, a Pearson chi-square test is used (with
Fisher's exact test as a fallback when any expected cell count \< 5).
For numeric predictors, a Wilcoxon rank-sum test is used.

## Examples

``` r
set.seed(9)
df <- data.frame(
  appt_date = c(rep(as.Date("2024-03-01"), 60), rep(NA, 20)),
  insurance = sample(c("BCBS", "Medicaid"), 80, replace = TRUE),
  physician = rep(paste0("Dr", 1:20), each = 4),
  stringsAsFactors = FALSE
)
mda <- mysterycall_missing_data_analysis(
  df,
  outcome_col   = "appt_date",
  group_col     = "insurance",
  covariate_cols = "physician"
)
#> Warning: Chi-squared approximation may be incorrect
print(mda)
#> === Missing Data Analysis ===
#> 
#> Overall: 20 missing / 80 total (25.0%)
#> 
#> -- Missingness by Group --
#>     group n_total n_observed n_missing pct_missing
#>      BCBS      47         33        14        29.8
#>  Medicaid      33         27         6        18.2
#> 
#> -- Statistical Tests (predictor vs. missingness) --
#>   variable n_observed n_missing pct_missing       test statistic df p_value
#>  insurance         80         0          25 Chi-square     1.393  1   0.238
#>  physician         80         0          25     Fisher        NA NA < 0.001
#>  significant
#>        FALSE
#>         TRUE
#> 
#> -- Interpretation --
#> 20 of 80 calls (25%) have a missing appointment date. Missingness was
#> significantly associated with: physician. This pattern is consistent with data
#> missing at random (MAR) conditional on observed covariates. Complete-case
#> analyses may underestimate the magnitude of insurance-related disparities;
#> consider multiple imputation or sensitivity analyses for robustness.
#> 
```
