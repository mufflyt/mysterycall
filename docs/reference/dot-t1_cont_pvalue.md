# Calculate P-Value for Continuous Variables

Uses Wilcoxon rank-sum or Kruskal-Wallis test.

## Usage

``` r
.t1_cont_pvalue(x, g)
```

## Arguments

- x:

  Numeric vector.

- g:

  Grouping vector.

## Value

Numeric p-value or NA.
